재난안전 기술 대국민 인식조사 — 리서치 합성 리포트

Method: 구조화 설문(Q5~Q30, 26문항) — LLM 합성 페르소나 1인칭 응답  |  Participants: 542명 (Nemotron-Personas-Korea × zai-glm-4.7, 17개 시도 층화·사후가중)

Date: 2026-06  |  Researcher: takeused  |  용도: 재난안전 R&D 기술로드맵 기획용 인식 진단

⚠ 본 리포트는 LLM 합성 응답 기반 가상조사 결과입니다. 실제 대국민조사 대비 평균은 근접하나 분산·소수의견은 작게 나타나므로, 경향·우선순위는 참고하되 정량 의사결정은 실제조사로 검증해야 합니다(상세: report_compare.html).
Executive Summary
국민은 재난안전 문제에 높은 관심·위기의식(관심 83%, 심각 99.6%)을 가지나, 정작 재난안전 과학기술(R&D) 인지도는 매우 낮다(2.12/5, '안다' 4.1%). 기술의 현재 효과·활용 체감은 보통(3.0/2.96)인 반면 보급 시 수용의향은 압도적(4.45/5, 99%)으로, '인지·접근성'이 핵심 병목임을 시사한다. 국민은 R&D의 중요성·투자필요성엔 압도적 동의(4.8/4.71)하되 효과성엔 신중(3.77)하며, 과학기술 역할을 '예방 단계'·'기술 접근성 보급'에서 기대한다. 정보는 TV·뉴스 등 전통매체 의존이 크고, 잠재 위협으로 기후변화·사이버범죄·시설 노후화·고령화를 꼽았다.

Key Themes

Theme 1. 높은 위기의식 ↔ 낮은 기술 인지 (Awareness Gap)전 응답자

재난 문제엔 민감하나, 그것을 다루는 과학기술의 존재·내용은 거의 모른다.
· Q5 관심도 3.92(관심 83%) / Q6 심각성 4.02(심각 99.6%)  vs  Q14 R&D 인지도 2.12('모른다' 84%, '안다' 4.1%)
→ R&D 성과가 국민 체감으로 연결되지 못함. 인지·소통 격차 해소가 1순위 과제.

Theme 2. 낮은 효과 체감 ↔ 압도적 수용의향 (Adoption Opportunity)기술 태도 전반

지금 기술이 잘 활용된다고 느끼진 않지만, 보급되면 적극 쓰겠다는 의향은 매우 높다.
· Q20 활용도 2.96 / Q16 해결가능성 3.03  vs  Q21 사용의향 4.45(그렇다 99%)
→ 수요는 충분. 기술개발보다 보급·접근성·체감화가 병목.

Theme 3. R&D 가치엔 압도적 지지, 효과성엔 유보 (Value vs Proof)R&D 평가 3문항

중요하고 투자도 필요하다는 데엔 강하게 동의하나, 실제 효과엔 상대적으로 신중하다.
· Q17 중요성 4.80 / Q19 투자필요성 4.71  vs  Q18 효과성·기여도 3.77
→ 효과 입증·실증 사례 제시가 신뢰의 다음 단계.

Theme 4. 기술 기대 = '예방 단계'·'접근성 보급' (Where Tech Should Help)역할 인식

사후 대응보다 사전 예방에, 첨단성보다 보급·접근성에 과학기술의 역할을 기대한다.
· Q27 기여 단계: 예측·예방 99%  ·  Q22 핵심요소: 기술 접근성·보급 87%(연구개발 10%)  ·  Q26 기여 기대: 화재·감염병·태풍
→ 로드맵 우선순위를 예방형·보급형 기술에 둘 근거.

Theme 5. 전통매체 의존 정보경로 (Channel)Q15

재난안전 기술 정보를 주로 TV·뉴스에서 접한다.
· Q15 1순위: TV·라디오 55% / 뉴스포털 31% / SNS 14% (정부·공공 플랫폼 0.3%)
→ 정부·공공 채널 도달 미미. 전통매체·언론 연계 소통 전략 필요.

Theme 6. '보통+' 안전감, 잠재위협은 신종복합형 (Emerging Risks)Q28·Q30

자기 지역은 보통~약간 안전하다 보나, 미래 위협으로 기후·사이버·고령화를 우려한다.
· Q28 거주지 안전도 3.49 · Q30 빈출: 기후변화·국지성호우·사이버/보이스피싱·시설 노후화·고령화
"최근 기후 변화로 예측 불가능한 국지성 호우나 폭염..." — P(40대)
"고령화와 디지털 기술 발전으로 AI 기반 보이스피싱이나 사이버 테러..." — P(고학력)
"동네가 낡아서 전기·가스 설비 노후화로 인한 화재가 걱정..." — P(저학력)
→ 단일재난형을 넘어 기후·디지털·고령사회 복합위험을 선제 관리 대상으로.

Recommendations

  1. [High] 인지격차 해소를 최우선 과제로 — 높은 관심(83%)을 R&D 인지·신뢰로 전환. TV·뉴스 등 실제 도달 채널 활용. (Theme 1·5)
  2. [High] '보급·접근성' 중심 R&D·정책 — 수용의향 99% 확보됨 → 개발보다 전달·체감화에 자원 배분. (Theme 2·4)
  3. [High] 예방형 기술 우선투자 — 기대가 예측·예방에 집중(99%). 조기경보·예측 로드맵 강화. (Theme 4)
  4. [Med] 효과 실증·공개로 신뢰 제고 — 중요성(4.8)·효과성(3.77) 간극을 사례로 메움. (Theme 3)
  5. [Med] 복합·신종재난 트랙 신설 — 기후·사이버·고령사회 위험. (Theme 6)

Questions for Further Research

  • 인지도 4%는 실제로도 그렇게 낮은가? (합성은 인지도 과소평가 가능 — 실제조사 교차검증)
  • '수용의향 99%'는 합성 긍정편향 가능 — 실측 87.7%와 비교 시 과대.
  • 예방단계 99% 쏠림은 합성 분산소멸 산물 — 실제(55.6%)와 큰 차이, 해석 주의.
  • 세그먼트별 미세 차이는 통계적으로 유의한가? (합성은 집단차 과소표현)
